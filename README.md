# 📊 Sales Dashboard

A responsive web-based sales analytics dashboard built for the Eureka Club Tech Team recruitment process.

## 🚀 Live Demo

**Deployed Link**: [https://sales-dashboard-navy-nu.vercel.app/]

**GitHub Repository**: [https://github.com/Shilpikumari26/Sales-Dashboard.git]

## 📋 Features

- ✅ Total Revenue calculation (displayed in ₹)
- ✅ Sales trends over time (monthly line chart)
- ✅ Sales distribution by region (doughnut chart) 
- ✅ Top 5 selling products by revenue
- ✅ Filtering by region, product, and date range
- ✅ CSV export functionality
- ✅ Fully responsive design

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (single file)
- **Charts**: Chart.js via CDN
- **Currency**: Indian Rupee (₹) formatting
- **API**: REST API integration

## 🚦 Getting Started

1. **Local Development**:
   ```bash
   # Open index.html in browser or use local server
   python -m http.server 8000
   ```

2. **Deploy to Vercel**:
   - Go to [vercel.com](https://vercel.com)
   - Upload your project folder
   - Click "Deploy"

## 🔍 API Integration

**Endpoint**: `https://68d424b8214be68f8c6887f1.mockapi.io/api/eureka/tech/task/sales`

The dashboard handles data cleaning automatically and displays all values in Indian Rupees (₹).

## 🎯 Key Metrics

- **Total Revenue**: Sum of all sales in ₹
- **Total Sales**: Count of transactions
- **Average Order Value**: Revenue per transaction in ₹
- **Products Sold**: Total quantity across all items
